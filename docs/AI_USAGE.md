## Day 1 — 2026-05-27

**사용**: 사전검수용 subagent 2회 호출

**관찰**:
- 1차 agent는 일반론·교과서 톤으로만 응답. 자료의 본문 인용 흔적이 부족했음
- "본문 발췌 인용 필수, 자료를 직접 읽어서 인용"이라고 명시 재지시하니 2차에서 자료 핵심 인용이 풍부해짐
- 같은 task를 두 번 시켰을 때 출력 깊이가 완전히 달랐음. 한 번에 안 끝나는 것이 일반 룰에 가까움

**메모**:
- AI 검수도 한 번 더 의심해서 재지시하는 흐름이 V&V 실천에 가까움
- 이 패턴 자체가 보고서 lessons learned 후보 (Issue #3)

**다음**: Day 2부터 코드 작성 0줄. AI 사용은 문서 작성·다이어그램 검토 보조에 한정. agent에게 prompt 줄 때 "본문 발췌 인용" 같은 검증 기준을 prompt에 명시.

## Day 2 — 2026-05-28

**사용**: 문서 작성 보조 + Mermaid 다이어그램 생성 + 어조 검수 후 전면 보완

**관찰**:
- Mermaid 다이어그램 생성 시 한 번 검수해서 채택. 자동 생성 그대로 commit하지 않음
- 어조 검수 받고 전면 보완 진행. AI 어투(명사 종결, em-dash, "솔직히:" 같은 어구, 출처 명시 등)가 문서 전반에 박혀있었음
- 검수 전까지 어조 문제를 자각하지 못했던 상태

**메모**:
- 어조 검수는 사람이 직접 해야 함. AI는 자기 출력의 AI 티를 감지하지 못함
- 다음부터 문서 작성 시 의식적으로 명사 종결 점 제거 + 짧은 하이픈 사용 + 출처 명시 회피
